# tiny-pine-lite

Rust · Terraform · Flutter

处理日常小任务的工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/tiny-pine-lite.git
cd tiny-pine-lite
cargo build --release
```
